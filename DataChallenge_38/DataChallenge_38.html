Importazione e pulizia dei dati

url <- paste0(
  "https://data.giss.nasa.gov/gistemp/",
  "tabledata_v4/GLB.Ts+dSST.csv"
)

temp_raw <- read_csv(
  url,
  skip = 1,
  na = c("***", "****"),
  show_col_types = FALSE
)

temp <- temp_raw |>
  select(Year, Jan:Dec) |>
  pivot_longer(
    cols = Jan:Dec,
    names_to = "month",
    values_to = "anomaly"
  ) |>
  mutate(
    month = factor(month, levels = month.abb),
    date = as.Date(
      paste(Year, month, "01", sep = "-"),
      format = "%Y-%b-%d"
    )
  ) |>
  drop_na(anomaly)

write_csv(temp, "anomaly.csv")

Creazione della data art

# voglio 144 anni (un numero quadrato)
df1 <- anomalies |>
  filter(1882 <= Year & Year <= 2025) |>
  select(Year, month, anomaly) |>
  mutate(Year = Year - 1882) |>
  rename(anno = Year, mese = month) |>
  mutate(centroX = (anno %% 12) + 1, centroY = 12 - (anno %/% 12))

Fissiamo dei parametri per l’opera.

a = 0.3
l = 0.5
df2 <- df1 |>
  mutate(veroCentroX = centroX + runif(nrow(df1), min = -a, max = a)) |>
  mutate(veroCentroY = centroY + runif(nrow(df1), min = -a, max = a)) |>
  mutate(angolo = runif(nrow(df1), min = 0, max = 2 * pi)) |>
  mutate(inizioX = veroCentroX + l * cos(angolo),
         inizioY = veroCentroY + l * sin(angolo),
         fineX = veroCentroX - l * cos(angolo),
         fineY = veroCentroY - l * sin(angolo))

Spiegazione del mapping della data art

Origine dell’opera

144 anni di storia climatica sono condensati in un unico quadrato. L’opera è costituita da un quadrato di lato 12, che contiene 144 piccoli quadrati, in ognuno dei quali sono collocati i dati relativi alle anomalie della temperatura in uno specifico anno (si parte dal 1882 in alto a sinistra e si finisce col 2025 in basso a destra). Ogni mese di un anno è rappresentato da un segmento colorato (il colore corrisponde all’anomalia). I segmenti sono disposti a caso nella regione di piano dedicata all’anno cui appartengono.

Significato

L’opera ricorda un tappeto dalle lunghe frange le cui fibre costitutive sono la storia climatica dell’ultimo secolo e mezzo del pianeta. Sebbene esse siano disposte casualmente a livello locale per ricordare che il fenomeno di cui fanno parte è estremamente complesso e imprevedibile, si nota chiaramente uno spostamento verso i colori più caldi, che diventa quasi oppressivo nella porzione più bassa. La metafora del tappeto rammenta allo spettatore che la responsabilità è dell’umanità che, come un “abile” artigiano, sta modificando il clima, purtroppo a proprio danno.
